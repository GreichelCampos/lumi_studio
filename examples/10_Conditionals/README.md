# Condicionales

- `01_If.lumi` demuestra una rama `si` verdadera.
- `02_If_Else.lumi` demuestra la selección entre `si` y `sino`.
- `03_Switch.lumi` demuestra `segun`, `caso` y `defecto`.

Las salidas esperadas son, respectivamente, `La habitacion es amplia`,
`Habitacion compacta` y `Material de madera`. Los tres ejemplos son válidos.
