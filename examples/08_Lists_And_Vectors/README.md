# Listas y vectores

- `01_Lists.lumi` declara y muestra listas de textos. La salida esperada contiene
  las listas completas de colores y materiales.
- `02_Vectors.lumi` reutiliza una variable `vector` como coordenada de una
  operación espacial. Debe generar una habitación con un mueble colocado.

Los dos ejemplos deben compilar y ejecutarse sin diagnósticos.
