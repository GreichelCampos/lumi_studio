# Variables y tipos de datos

- `01_Data_Types.lumi` declara y muestra valores `entero`, `decimal`, `texto`,
  `booleano` y `nulo`. Debe terminar sin diagnósticos y mostrar los cinco valores.
- `02_Assignments.lumi` reasigna variables conservando sus tipos. Debe mostrar
  `Cantidad final:`, `5`, `Estado final:` y `completado`.

Ambos ejemplos son ejecutables de consola y no generan una escena 3D.
